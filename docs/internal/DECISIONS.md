# image-ultra — Decision Log

Format: date · decision · why · alternatives rejected.

1. **2026-09-24 · Rewrite in TS, don't fork Filerobot.** Filerobot is JS + styled-components + @scaleflex/ui + react-konva; runtime CSS-in-JS breaks with RSC and the UI kit makes styling inconsistent. Filerobot = feature checklist only.
2. **2026-09-24 · Pintura = UX inspiration only.** Commercial license; we recreate the feel with our own code, icons, assets.
3. **2026-09-24 · Name `image-ultra`, MIT.** Scoped packages `@image-ultra/core`, `@image-ultra/react`. Names verified free on npm that day.
4. **2026-09-24 · Framework-agnostic core.** Core has zero React so a Web Component / other frameworks can reuse it.
5. **2026-09-24 · Plain CSS + CSS variables in `@layer image-ultra`.** SSR-safe, zero runtime, overridable. Rejected: styled-components, emotion (runtime), Tailwind (forces setup on consumers).
6. **2026-09-24 · Radix primitives for behaviour only** (popover, tooltip, slider a11y), always unstyled and wrapped by our components. Rejected: full UI kits.
7. **2026-09-24 · Zustand vanilla store + Immer patches** for state/undo. Small, typed, works outside React.
8. **2026-09-24 · WebGL2 for pixel ops, Canvas2D for vector + fallback.** Real-time sliders on large images. Rejected: Konva (extra dependency, React wrapper, we only need a thin shape layer).
9. **2026-09-24 · Container queries for responsiveness**, because the editor can be embedded in any sized box.
10. **2026-09-24 · pnpm + Turborepo monorepo, tsup build (ESM + CJS + d.ts).**
11. **2026-09-24 · Build with TypeScript 6.0.3, not 7.** TS 7 (native Go compiler) has no JS API, and typescript-eslint (`<6.1`), tsup's dts step and Next's type check all need it. Revisit when the tooling supports TS 7. Consumers may use TS 7 — we ship plain `.d.ts`.
12. **2026-09-24 · tsup `dts.compilerOptions.ignoreDeprecations: '6.0'`** because tsup injects the deprecated `baseUrl`.
13. **2026-09-24 · Wheel = zoom around cursor** (mouse wheel and trackpad pinch), drag = pan when zoomed past fit, double-click toggles fit ↔ 100%. Space+drag pan comes in Phase 3, when plain drag gains tool meaning (crop).
14. **2026-09-24 · Pixels render crisp (no smoothing) at ≥ 300% zoom** so users can inspect detail.
15. **2026-09-24 · Stage paints outside React**: it subscribes to the store and redraws once per animation frame; React only renders chrome. Canvas2D in Phase 1, WebGL2 pipeline arrives in Phase 2.
16. **2026-09-24 · Keyboard shortcuts live on `.iu-root`** (only fire while focus is inside the editor, never global): `+`/`=` zoom in, `-` zoom out, `0` fit, `1` 100%.
17. **2026-09-24 · All 8 AI features are in plan** (owner). Phase 9 in `@image-ultra/plugin-ai`, auto-enhance in core (Phase 4). AI outputs stay non-destructive: parameters where possible, otherwise rasters in `EditState.assets` with the recorded inputs. Phase 2 (async plugin actions + assets registry) and Phase 5 (brush/mask tool) must leave hooks for this.
18. **2026-09-24 · AI appears inside the tool it belongs to**, plus one "Magic" tool for standalone actions. Default models must be MIT/Apache/BSD licensed.
19. **2026-09-24 · Brand primary = plum `#4d194d`** (owner). Exact value in the light theme; dark theme uses same-hue tints (`#9c479c` / `#ab55ab` / text `#d08bd0`) because `#4d194d` is only 1.4:1 on dark surfaces. New token `--iu-accent-text` for accent-coloured text/icons.
20. **2026-09-24 · History = immutable snapshots, not Immer patches** (refines #7). EditState is small JSON and Immer shares unchanged parts between snapshots, so snapshots cost little and make undo/redo exact and trivially correct. Default limit 250 steps (`historyLimit`).
21. **2026-09-24 · Store action is `update(label, recipe)`** (the state field is `edit`). Continuous input uses `beginChange` → `update`… → `endChange` (one undo step) or `cancelChange`.
22. **2026-09-24 · `onChange` fires once per committed edit** — not per frame of a slider drag and not on image load — so apps can safely save to a server from it.
23. **2026-09-24 · One render pipeline for preview and export.** Output px → source px is a single affine matrix (`getOutputToSource`); the WebGL2 shader and the Canvas2D fallback both use it plus the same colour math (`color.ts` ≡ `shaders.ts`). E2E test: renderers match within 2/255 at full size. Downscaled exports differ slightly (GPU mipmaps vs browser resampler) — accepted.
24. **2026-09-24 · Colour pipeline order:** exposure + white balance in linear light → brightness, contrast, gamma, saturation in sRGB → vignette. Finetune values are all −1…1 with 0 = neutral.
25. **2026-09-24 · Images larger than the GPU texture limit** are downscaled for WebGL (usually 16384px on desktop, 4096–8192 on mobile). Exports are capped at the renderer's max output size. Tiling = Phase 7.
26. **2026-09-24 · Preview renderers never destroy the canvas's GPU context on dispose** (React StrictMode remounts reuse the canvas); only renderers that own their canvas (export) do (`ownsCanvas`).
27. **2026-09-24 · Playground dev panel** (`apps/playground/app/DevPanel.tsx`) exercises the engine through the public ref API until real tool UIs exist. It is not part of the package and follows no UI_VISION rules. `window.__iu` is a test hook for Playwright only.
28. **2026-09-24 · Geometry uses projective 3×3 matrices (`Mat3`)** so perspective fits the same single-matrix pipeline. The shader divides by z; the Canvas2D fallback draws a 20×20 triangle mesh when the transform isn't affine (small, accepted differences; e2e mean diff < 3/255).
29. **2026-09-24 · Perspective = an in-plane rotation vector (Rodrigues)**, not Ry·Rx, so 90° turns and flips map it exactly: CW (x, y) → (y, −x), flipX negates x, flipY negates y. Max tilt 30°, focal length = longest oriented side.
30. **2026-09-24 · Crop lives in "oriented space"** (after rotation/flip/straighten/perspective, origin at the rotated-but-unstraightened frame). Rotating/flipping transforms the crop rect so the result turns exactly as seen. A crop is valid when all 4 corners map inside the source image (binary-search fitting for move/resize/auto-fit).
31. **2026-09-24 · Angle changes shrink the crop around its centre (same aspect)** using the crop from the start of the drag as reference, so returning the dial to 0 restores the original crop. Resize follows the crop's aspect when a crop changes (`syncResizeToCrop`).
32. **2026-09-24 · Crop view is owned by the Adjust overlay** (`store.cropView`): the stage renders the image's full bounding box framed around the crop while the overlay is mounted, and returns to the result view when it unmounts. Wheel/pan/zoom are off in crop view.
33. **2026-09-24 · Tools are plugins**: `defineTool({ id, label?, icon, Controls, StageOverlay? })`. Built-ins are registered the same way; `tools` accepts ids and definitions. `activeTool` became `string`. Space+drag pan (old #13) dropped — in crop view dragging already moves the image.
34. **2026-09-24 · Social size presets live in `SIZE_PRESETS`** (English labels, brand names). A `sizePresets` prop for custom/translated lists can come later if needed.
35. **2026-09-24 · Colour pipeline order:** filter (matrix → filter curves, blended by intensity) → exposure/white balance (linear) → brightness, contrast, gamma, highlights/shadows → saturation, vibrance, hue → levels + curves (one LUT) → detail (clarity/sharpen/blur) → vignette, grain, round mask. Filter first so finetune tweaks the filtered look.
36. **2026-09-24 · Filters are stored in full** (`EditState.filter` = id, name, intensity, 3×4 matrix, curves), not by id, so a saved state renders identically anywhere — even with a custom or removed preset list. No bitmap LUTs; `.cube` 3D LUT import could come later.
37. **2026-09-24 · Curves/levels → one 256-entry RGBA8 LUT** (levels, then channel curve, then RGB curve), shared by GPU (texture, linear filtering) and CPU (`sampleLUT`, same interpolation) for exact parity. Curves use monotone cubic interpolation (no overshoot).
38. **2026-09-24 · Detail effects are multi-pass on the GPU** (colour → FBO → separable Gaussian, downsampled ×1–4 for large radii → finish). Radii are relative to the output size (sharpen 0.12%, clarity 2%, blur up to 3% of the short side) so preview, thumbnails and export look alike. CPU fallback uses 3× box blur (close, not identical: e2e mean diff < 3/255). Without detail effects everything stays single-pass.
39. **2026-09-24 · Grain uses an integer hash** (same bits in GLSL `uint` and JS `Math.imul`), in output-pixel cells of `max(1, shortSide/1500)`, so grain is deterministic and identical on GPU/CPU.
40. **2026-09-24 · Round-crop edge uses analytic anti-aliasing** (`u_ellipseAA` = one canvas pixel in ellipse units) instead of `fwidth`, for GPU/CPU parity. Parity is measured on premultiplied colour (near-transparent RGB is noise).
41. **2026-09-24 · Auto-enhance = deterministic analysis, no ML:** 0.5% luma clip for black/white (max 12% crush), mid-tones only corrected outside 0.38…0.6, gray-world WB at 60% strength, gentle vibrance/contrast/shadows/highlights. Analysed on a 256px render of the geometry only.
42. **2026-09-24 · Looks** = finetune + levels + curves + filter (no geometry). Uncontrolled: localStorage key `image-ultra:looks` (`persistLooks` to change/disable). Controlled: `looks` + `onLooksChange`.
43. **2026-09-24 · ControlBar is 148px** (was 136) to fit Curves/Levels without scrolling; padding 10px vertical. Added `IconButton size="sm"` (24px) for secondary actions in dense panels.
44. **2026-09-24 · Saved looks are shown first in the Filter tool** (after "Original", with a bookmark badge and a divider before presets), and saving shows an inline "View in Filters" link — owner couldn't find looks at the end of 28 presets. `SegmentedControl` is `width: fit-content` so it never stretches inside grid cells.
45. **2026-09-24 · Annotations live in oriented space** (same as the crop): cropping never moves them relative to the photo; rotate/flip transform them exactly (box shapes turn with the photo; text/images are repositioned and their angle mirrored but never drawn mirrored); straighten/perspective leave them upright. Stored in `EditState.annotations` (bottom → top).
46. **2026-09-24 · Annotations are vectors drawn with Canvas2D after the GPU image** — in the Stage (separate canvas layer) and in export (`renderToCanvas`) — so they stay sharp, aren't colour-graded, and are clipped by a round crop. Export waits for fonts and image assets.
47. **2026-09-24 · Shape model:** rect, ellipse, line (caps none/arrow/circle), path (pen = smooth, polygon = straight + closed), text (box width + wrap, height derived by measuring), image (asset id → `EditState.assets`, inserted as ≤1600px WebP data URL). Sizes are image pixels; defaults are relative to the visible crop (S/M/L/XL). Colours in state are validated as plain colour strings only.
48. **2026-09-24 · Radix Popover** (`@radix-ui/react-popover`) for all inspector popovers, portalled into a `.iu-portal` element inside `.iu-root` so theme variables and `@layer` styles apply.
49. **2026-09-24 · Tools can share transient UI state** between Controls and StageOverlay via `useToolState()` (backed by `store.toolState[toolId]`, outside history).
50. **2026-09-24 · The stage and tool overlays take keyboard focus on pointer-down** (tabIndex −1, no mouse focus ring) so shortcuts work right after clicking the photo. Tool shortcuts are single letters only while the tool is active; keys inside popovers/panels are ignored.
51. **2026-09-24 · Creating text prevents the pointer-down default** (focus change) and focuses the editor on the next frame — otherwise the new box blurred and was discarded immediately.
52. **2026-09-24 · Inline style rule: never mix a CSS shorthand with its longhands** (e.g. `font` + `lineHeight`) in React `style` — React warns and can drop values on re-render. Use longhands.
53. **2026-09-24 · Re-editing text puts the caret at the end** (no select-all), so the first keystroke never replaces existing text.
54. **2026-09-24 · Preview WebGL canvas uses `premultipliedAlpha: true`** (pixels are always opaque or empty thanks to the checkerboard); exports keep `false`. Note: "GPU stall due to ReadPixels" console messages come from headless Chrome's software compositing of any WebGL canvas — verified with a bare WebGL page; not present in a normal browser.
55. **2026-09-25 · Tooltips = one shared `TooltipLayer`, not Radix Tooltip** (updates #6 for tooltips). Any element with `data-tooltip="…"` inside the editor gets it — no wrapper per button, so it also covers Popover/Menu triggers and custom tools' buttons. Rendered in `.iu-portal` with `position: fixed` (panels with `overflow` can't clip it), below the element or flipped above, clamped to the window; 400ms delay, instant when moving between neighbours (300ms), keyboard focus shows it, touch never does. `aria-hidden` because it repeats the button's `aria-label`. z-index = the toast layer so it sits above popovers.
56. **2026-09-25 · Load errors are typed and never uncaught.** `ImageLoadError.code` = `unsupported` (real image, format this browser can't show — e.g. HEIC), `damaged`, `not-image`, `network`; the format is sniffed from the file's first bytes (`detectImageFormat`), not the extension. When `createImageBitmap` fails we retry through an `<img>` element (SVG everywhere, ICO/HEIC where the browser supports them); viewBox-only SVGs are drawn at 1024px on the long side. Preview render failures go to `store.fail()` → the error screen. Without `onError`, errors go to `console.warn` (a bad file is a user mistake; Next's dev overlay treats `console.error` as an app crash).
57. **2026-09-25 · A click on a shape with a drawing tool selects it and switches to Select** (Pen, Line, Arrow, Rectangle, Ellipse; Polygon only before its first point; Text for non-text shapes). A **drag** that starts on a shape still draws (Pen/shapes) — except on the already selected shape, which it moves.
58. **2026-09-25 · Text never vanishes.** A new box reads "Text" (`labels.textDefault`), fully selected so typing replaces it; an emptied box gets "Text" back when you leave it (owner's choice). Only Delete removes text. With the Text tool, clicking a text box edits it with the caret at the click (`textIndexAt`); dragging moves it. Double-click / Enter still put the caret at the end (#53).
59. **2026-09-25 · Shape context menu = Radix Dropdown Menu** (`@radix-ui/react-dropdown-menu`, non-modal) opened from an invisible anchor at the pointer: right-click (hit-test includes **locked** shapes), touch long-press (500ms; iOS has no `contextmenu`), Shift+F10 / Menu key for the selected shape, and a "⋯" button on each Layers row. Items: Lock/Unlock, Hide/Show, Bring to front/forward, Send backward/to back, Duplicate, Delete (disabled while locked), Show in Layers. Actions live in `tools/annotate/actions.ts`, shared with the Layers panel and shortcuts. Focus returns to the photo when the menu closes (Radix can report the close twice).
60. **2026-09-25 · Editing text = click the selected text box** (Select tool), or any text box with the Text tool; caret at the click. Double-click still works. **The Stage only zooms on double-click when the press reached it** — it records presses in the capture phase and clears the flag in its own `onPointerDown`, so any tool overlay that claims a press (`stopPropagation`: shapes, handles, drawing, the text editor) also blocks the zoom. (A `dblclick` is dispatched to the common ancestor of both clicks — here the stage itself — so stopping it in the overlay can't work.)
61. **2026-09-25 · Annotate selection is cleared by a press outside the editor or on non-interactive editor chrome** (toolbar/ControlBar background). Presses on controls keep it (they edit the selected shape), as do popovers/menus (`.iu-portal`), the photo layer and the Layers panel. "No colour" is shown as a transparency checkerboard (theme-aware via `color-mix` on `--iu-text`), not a red slash.
62. **2026-09-25 · Phase 6 scope:** Sticker is built in Phase 6 (reuses image shapes); multi-select moves to Phase 7. Order: compare/history/shortcuts → Redact → Frame & Fill → Watermark & Sticker → EXIF + copy/paste.
63. **2026-09-25 · Compare shows "before" = same framing, no look.** The before image keeps the current geometry (crop, rotation, straighten, perspective) and resize, and drops everything else (finetune, filter, levels, curves, annotations — and later redaction, frame, watermark), so both sides line up exactly (`getBeforeState`). It renders on its own canvas above the photo, clipped at the divider; annotations are clipped to the "after" side. `store.compare`: `null` = off, `1` = whole image is "before" (hold), `0…1` = split position. UI-only: never affects `EditState`, export or history.
64. **2026-09-25 · History and keyboard shortcuts are TopBar popovers** (not panels or modal dialogs), consistent with "popovers are the only floating UI". History lists "Original" + every step label; click jumps (repeated undo/redo, so redo stays available). Shortcuts opens with `?` too and shows ⌘ on Apple devices, Ctrl elsewhere.
65. **2026-09-25 · Phones keep zoom and History in the TopBar** (owner); only Keyboard shortcuts hide. Fitting 320px: −/+ drop below 480px (the % button + pinch remain), Done goes icon-only (label stays for screen readers), TopBar buttons 34px with 2px gaps below 360px (`--iu-size-topbar-compact`); elsewhere buttons always keep a 4px gap so hover/active backgrounds never touch (owner, 2026-09-25).
66. **2026-09-25 · Text editing ends on any press outside the photo layer**, committed explicitly from a document-level listener — not only on the text box's blur, because Safari doesn't move focus to clicked buttons. The Text tool creates boxes only on the photo (inside the crop); a click on the dark stage around it just deselects. Shape tools likewise don't drop a default shape on a click outside the photo (drags may start there).
67. **2026-09-25 · Text edits like Canva: one mode.** A text box being edited keeps its resize/rotate handles (a second SVG above the text box; the dashed edit outline replaces the solid selection outline). Dragging a handle while editing prevents the pointer-down default so the text box keeps focus, joins the open "Edit text" change (typing + resizing = one undo step) and editing continues afterwards.
