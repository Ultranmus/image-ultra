## Commands & gotchas

- Run: `pnpm playground` → http://localhost:3100 (builds packages, then `next dev`).
- Checks: `pnpm lint`, `pnpm build`, `pnpm typecheck`, `pnpm test` (Vitest), `pnpm e2e` (Playwright, 34 tests).
  Run e2e with stdin closed (`< /dev/null`) and free port 3100 first (`lsof -ti tcp:3100 | xargs kill`).
- Playwright `webServer` starts `node node_modules/next/dist/bin/next start` directly (pnpm doesn't forward
  SIGTERM → teardown hangs). Build the playground before e2e if packages changed (`pnpm build`).
- Toolchain: Node 24, pnpm 12.6 (corepack), **TypeScript 6.0.3** (not 7 — tooling needs the TS JS API),
  React 19, Next 16. `pnpm-workspace.yaml` has `allowBuilds` for esbuild/sharp.
- Prettier reformats long lines → Python/sed string replacements often stop matching after a
  `pnpm prettier --write`; re-read the file first.
- Headless Chrome logs "GPU stall due to ReadPixels" for any WebGL canvas — not our bug (DECISIONS #54).
- The owner keeps the Mac awake with `caffeinate -dims` during long work; on battery, closing the lid still sleeps.
